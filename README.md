# 🌿 Shrawan Shakarti Digital Fest

A full-stack web application built with Django REST Framework and React (Vite).

## 🚀 Live Demo

🔹 Frontend:  
https://shrawan-shakarti-digital-fest-5.onrender.com

🔹 Backend API:  
https://shrawan-shakarti-digital-fest-4.onrender.com

---

## 🛠 Tech Stack

- Django REST Framework
- PostgreSQL (Render)
- React (Vite)
- JWT Authentication
- Gunicorn
- Render Deployment

---

## ✨ Features

- ✅ User Registration & Login (JWT)
- ✅ Surprise Page (First Login Feature)
- ✅ Profile Update with Photo Upload
- ✅ Change Password
- ✅ Protected Routes
- ✅ Token Auto Refresh
- ✅ Fully Deployed on Render
